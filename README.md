# Minecraft Tools

A collection of useful tools for everyday Minecraft play: stack calculator, item checklist and more.

**Stack:** Vite · TanStack Router (file-based) · React 19 · Tailwind v4 · shadcn/ui on Base UI · oxlint + oxfmt · Bun

## Development

```bash
bun install
bun dev            # http://localhost:5173
bun run build      # type-check + production build in dist/
bun run lint       # oxlint
bun run format     # oxfmt
```

Routes live in `src/routes/` (`src/routeTree.gen.ts` is generated by the router plugin).
The build output is a static SPA, so the host must rewrite unknown paths to `index.html`.

## Updating items for a new Minecraft version

Item icons live in `public/items/<item_id>.webp` (128×128) and the checklist reads `src/data/items.json`.

```bash
bun run items:sync            # latest release
bun run items:sync 1.21.11    # a specific version
```

The script downloads the official client jar (cached in `.cache/`), reads the item ids and English
names straight from the game assets, and compares them with `public/items/`. It then:

- regenerates `src/data/items.json` from the items that have an icon;
- lists **missing icons** (new items): add `public/items/<id>.webp` for each and run it again;
- lists **orphaned icons** (renamed/removed items): delete or rename those files.

The sync is done when the script prints `Everything is in sync.`
