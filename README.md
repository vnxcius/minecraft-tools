# Minecraft Tools

A collection of useful tools for everyday Minecraft play: stack calculator, item checklist and more.

**Stack:** Vite · TanStack Router (file-based) · React 19 · Tailwind v4 · shadcn/ui on Base UI · oxlint + oxfmt · Bun

## Development

```bash
bun install
bun dev            # http://localhost:5173
bun run build      # type-check + production build in dist/
bun run lint       # oxlint
bun run format     # oxfmt
```

Routes live in `src/routes/` (`src/routeTree.gen.ts` is generated by the router plugin).
The build output is a static SPA, so the host must rewrite unknown paths to `index.html`.

## Item icons and versions

Item icons are served from the public [mcitemgallery.com](https://mcitemgallery.com) CDN
(`/images` is incremental, `/images-v2` ships full sets), so nothing is stored in this repo.
What we keep is a small catalog under `src/data/`:

- `versions.json`: available Minecraft versions (newest first) and their CDN source
- `item-names.json`: item id to display name
- `items/<version>.json`: item id to the CDN folder that holds its icon for that version

The checklist picks the version from `?v=` (latest when missing) and lazy-loads only that version's file.

To pick up a new version published on the CDN:

```bash
bun run items:sync
```

The script reads the CDN manifests, resolves which folder holds the icon of every item per version
and rewrites `src/data/`. Commit the result.
